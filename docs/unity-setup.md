# Запуск проекта в Unity (пошагово)

Всё бесплатно. Нужен компьютер на Windows 10/11 или macOS: от 8 ГБ ОЗУ (лучше 16) и ~25 ГБ на диске.

## 1. Скачать проект

**Вариант А — без программ (проще всего):**
1. Откройте https://github.com/primehard1-dev/cats
2. Слева сверху кнопка с названием ветки (обычно `main`) → выберите **`ccr-cf051de6-y08ep0`**.
3. Зелёная кнопка **Code** → **Download ZIP**.
4. Распакуйте архив в папку **без русских букв и пробелов**, например `C:\Games\cats`.
   Внутри будет папка `CatsGame` — это и есть Unity-проект.

**Вариант Б — GitHub Desktop** (удобно получать мои обновления):
1. Установите https://desktop.github.com и войдите в аккаунт GitHub.
2. File → Clone repository → `primehard1-dev/cats` → путь `C:\Games\cats`.
3. Вверху **Current branch** → `ccr-cf051de6-y08ep0`.
4. Потом, когда я что-то исправлю: кнопка **Fetch origin** → **Pull**.

## 2. Установить Unity

1. Скачайте **Unity Hub**: https://unity.com/download → установите → войдите
   (аккаунт Unity бесплатный; при первом входе Hub выдаст лицензию **Personal**).
2. В Hub: **Installs** → **Install Editor** → вкладка **Official releases** →
   **Unity 6** (6000.0 LTS или новее, например 6000.6 — проект настроен на 6000.6.1f1).
3. На шаге модулей отметьте:
   - ☑ **Android Build Support**
     - ☑ OpenJDK
     - ☑ Android SDK & NDK Tools
   - (Visual Studio можно оставить — пригодится, если захотите смотреть код)
4. Установка займёт 15–40 минут в зависимости от интернета.

## 3. Открыть проект

1. Hub → **Projects** → **Add** → **Add project from disk** → выберите папку **`CatsGame`**
   (не `cats`, а именно `CatsGame` внутри).
2. Если Hub предложит версию редактора — выберите установленную Unity 6.
3. Первое открытие долгое (5–20 минут): Unity импортирует текстуры, модели, звуки.
4. Если появится окно про **Input System** («enable the new input backends? restart?») — нажмите **Yes**,
   Unity перезапустится.
5. Если спросит про обновление проекта/пакетов — **Continue / Yes**.

## 4. Собрать игру внутри Unity

В верхнем меню редактора появится пункт **Cats**:

1. **Cats ▸ 0. Do everything** — настроит проект под Android, создаст материалы, префабы,
   сцену меню и сцену уровня (1–3 минуты).
2. **Cats ▸ 4. Bake lighting** — запекание света. Прогресс — справа внизу. 5–15 минут на видеокарте;
   если видеокарты нет — дольше. Дождитесь, пока полоска исчезнет.
3. **Cats ▸ 5. Open main menu**.
4. Кнопка **▶ Play** вверху по центру.

Управление в редакторе: **WASD** — идти (Shift — бег), **пробел** — прыжок, **M** — мяу,
**правая кнопка мыши** — повернуть камеру, **Esc** — пауза.

Совет: вкладка **Game** → выпадающий список разрешения → добавьте **2400×1080** (как телефон).

## 5. Что прислать мне

1. Скриншот вкладки **Console** (внизу; если её нет — Window → General → Console).
   Особенно важны **красные** строки.
2. Скриншот стартового кадра (после затемнения).
3. Скриншот кота вблизи (подойдите и поверните камеру).
4. Если что-то выглядит странно — опишите словами: «хвост вниз», «лужи чёрные», «кот летает».

## 6. На телефон (когда всё заработает)

1. На телефоне: Настройки → О телефоне → 7 раз нажать **Номер сборки** → в «Для разработчиков»
   включить **Отладку по USB**. Подключить кабелем, разрешить отладку.
2. В Unity: **File ▸ Build Profiles** → **Android** → **Switch Platform** (один раз, 5–15 минут).
3. **Build And Run** → выберите, куда сохранить `.apk`. Игра установится и запустится на телефоне.

## Частые проблемы

| Что видно | Что сделать |
|---|---|
| Всё розовое | Ещё раз **Cats ▸ 0** (значит, URP не успел включиться до создания материалов) |
| Нет пункта меню **Cats** | В Console красные ошибки компиляции — пришлите скриншот |
| Сцена тёмная и плоская | Не было запекания: **Cats ▸ 4** и дождаться конца |
| Запекание очень долгое | Window ▸ Rendering ▸ Lighting → Lightmapper → **Progressive CPU** или уменьшить Lightmap Resolution до 6 |
| Кнопки на экране не нажимаются | Пришлите скриншот Console (скорее всего, модуль ввода) |
| Android-сборка ругается на SDK/JDK | Hub → Installs → ⚙ у Unity 6 → Add modules → проверьте Android SDK/NDK/OpenJDK |
