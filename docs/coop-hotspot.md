# Совместная игра через точку доступа (план)

Цель: два телефона, один раздаёт Wi-Fi (точку доступа), второй к нему подключается.
Интернет не нужен. Каждый игрок управляет своим котом и видит игру своей камерой.

## Что уже заложено в коде

| Что | Где | Зачем |
|---|---|---|
| Кот управляется кадром ввода `CatInputFrame` (движение уже в мировых координатах + прыжок) | `Scripts/Runtime/Cat/CatInput.cs` | Этот же кадр можно передавать по сети, контроллеру всё равно, откуда он пришёл |
| Источник ввода — подменяемый компонент `CatInputSource` | `LocalCatInput` сейчас, `NetworkCatInput` потом | Второй кот получает ввод от второго телефона |
| Камера — отдельный риг на игрока (`CatCameraRig`) | `Scripts/Runtime/Camera` | Каждый телефон рендерит свою камеру, камеры не синхронизируются |
| Игроки хранятся списком `GameManager.players` (у каждого свой чекпоинт) | `Scripts/Runtime/Game/GameManager.cs` | Респаун и чекпоинты работают на каждого кота отдельно |
| Точка появления второго кота | объект `SpawnPlayer2 (co-op)` в сцене | Рядом с первым котом на террасе |
| Свет запечён, анимации процедурные и детерминированные | — | По сети не нужно гонять ничего, кроме позиций котов и событий |

## Как это будет сделано

1. **Пакеты:** `com.unity.netcode.gameobjects` (Netcode for GameObjects) + `com.unity.transport` (UDP).
2. **Роли:** телефон с точкой доступа запускает **Host** (сервер + игрок), второй — **Client**.
3. **Поиск без ввода IP:** хост раз в секунду шлёт UDP-broadcast на порт 47777
   (`"CATS|<имя>|<порт>"`), клиент слушает и показывает кнопку «Присоединиться к <имя>».
   На Android для приёма broadcast нужен `WifiManager.MulticastLock`.
4. **Синхронизация:**
   - позиция и поворот кота: `NetworkTransform` с интерполяцией, 20–30 Гц, owner-authoritative
     (каждый телефон сам считает своего кота — так нет задержки управления);
   - состояние для анимации (`State`, `Speed01`, `Balance`) — `NetworkVariable`;
   - события (чекпоинт, конец уровня, упавший горшок) — RPC.
5. **Уровень:** второй кот начинает рядом с первым. Прыжки по лапкам работают для обоих.
   Гирлянда выдерживает обоих, но баланс у каждого свой. Финал засчитывается,
   когда оба кота у причала.
6. **Трафик:** около 2–4 КБ/с — точка доступа телефона тянет с большим запасом.

## Оценка работ

- Лобби (хост / поиск / подключение) + спаун второго кота — 2–3 дня.
- Синхронизация движения и анимации — 2 дня.
- Общие события, финал, переподключение — 2 дня.
- Тест на двух реальных телефонах: задержка, потеря пакетов, сон экрана — 1–2 дня.
